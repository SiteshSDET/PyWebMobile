# Selenium Python Pytest Automation Framework

Industry-level UI automation framework using:

- Python
- Selenium WebDriver
- Pytest
- Page Object Model
- Explicit Waits
- Pytest Fixtures
- Logging
- Screenshot on Failure
- Configuration Management
- Data-Driven Testing
- Allure Reporting
- Parallel Execution
